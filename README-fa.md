# bim-mcp 🇹🇷

mcp-name: io.github.mohammad-abbasi-sh/bim-mcp

سرور MCP غیررسمی و **فقط‌خواندنی** برای bim.com.tr (شرکت BİM Birleşik Mağazalar A.Ş. — بزرگ‌ترین زنجیرهٔ فروشگاه‌های تخفیفی ترکیه، ۱۳٬۰۳۲ شعبه در ترکیه تا ۳۰٫۰۶٫۲۰۲۶). پیشنهادهای هفتگی «آکتوئل» همراه با قیمت، جست‌وجوی محصول، آمار قیمت، ۱۱ دستهٔ محصولات و ۸۱ استان در یابندهٔ فروشگاه.

> ساختهٔ محمد عباسی در چارچوب «کارخانهٔ MCP ترکیه» (خط لوله به سبک سپهر). وابسته به bim.com.tr یا BİM نیست.

## برای ایجنت‌های هوش مصنوعی

به پیکربندی کلاینت MCP خود اضافه کنید (stdio):

```json
{
  "mcpServers": {
    "bim": {
      "command": "uvx",
      "args": ["bim-mcp==0.1.0"]
    }
  }
}
```

یا به‌صورت محلی اجرا کنید: `python -m bim_mcp.server` (نیازمند `mcp<2` و `curl-cffi`).

## ابزارها

| ابزار | توضیح |
|------|--------|
| `bim_list_aktuel_dates` | دوره‌های زمانی «آکتوئل» و «ایندیریم» — کلید تاریخ، برچسب ترکی (مثلاً «03 Kasım Salı»)، نوع («aktuel»/«indirim») |
| `bim_aktuel_products` | محصولات قیمت‌دار آکتوئل یک هفته — `date_key` (برای هفتهٔ جاری خالی بگذارید)؛ `query` فیلتر زیررشته‌ای ترکی (مثلاً «yağ»، «pirinç»)؛ `sort` («price_asc»/«price_desc»/«name»)؛ `limit` ۱ تا ۱۰۰؛ برند، نام، اندازه، قیمت به لیر (TRY)، تصویر، نشانی محصول، slug و شناسهٔ BİM |
| `bim_product_detail` | جزئیات کامل یک محصول — `slug` از نشانی محصول (مثلاً «aycicek-yagi-pet-sise-26-10»)؛ نام، اندازه، قیمت جاری (TRY)، تصویر بزرگ، شناسهٔ BİM (در صفحهٔ جزئیات برند نیست — برند از فهرست می‌آید) |
| `bim_price_stats` | آمار قیمت یک هفته — تعداد، کمترین/میانه/میانگین/بیشترین قیمت (TRY)، ۵ ارزان‌ترین و ۵ گران‌ترین محصول |
| `bim_list_categories` | ۱۱ دستهٔ محصولات (Süt ve Süt Ürünleri، İçecekler و...) — شناسه، نام، slug و نشانی |
| `bim_list_cities` | ۸۱ استان ترکیه در یابندهٔ فروشگاه BİM (شناسه + نام). نشانی فروشگاه‌ها به‌تفکیک استان در دسترس نیست — جست‌وجوی یابنده در سایت نیازمند نشست (session) است |

خروجی نمونه (`bim_aktuel_products` / هفتهٔ ۰۳ نوامبر ۲۰۲۶):

```json
{"brand": "TURNA", "name": "AYÇİÇEK YAĞI PET ŞİŞE", "size": "5 L",
 "price_try": 429.0,
 "image_url": "https://cdn1.bim.com.tr/uploads/aktuel-urunler/1697_kucuk_543X467_2080_gda_0051_vector-smart-object.jpg",
 "url": "https://www.bim.com.tr/aktuel-urunler/aycicek-yagi-pet-sise-26-10/aktuel.aspx",
 "slug": "aycicek-yagi-pet-sise-26-10", "bim_id": "72460"}
```

## چگونه کار می‌کند؟

سایت bim.com.tr صفحات آکتوئل را کاملاً سمت سرور ارائه می‌دهد — بدون ورود، بدون کلید API و بدون کوکی نشست. منوی تاریخ آکتوئل/ایندیریم جدولی درون `<div class="subMenu aktuelsubmenu">` است (ردیف‌ها به `?top=1&Bim_AktuelTarihKey=<key>` پیوند می‌دهند). محصولات کارت‌های `<div class="product ...">` هستند: برند در `<h2 class="subTitle">`، نام در `<h2 class="title">`، اندازه در `<div class="gramajadet">`، و قیمت به‌صورت جدا `<div class="text quantify">429,</div>` + `<span class="number">00</span>` + `<span class="curr">₺</span>` (قالب ترکی: «.» هزارگان، «,» اعشار). از حدود ۹۵ بلوک هر هفته، ۲ بلوک فقط تصویرند و قیمت ندارند و نادیده گرفته می‌شوند. دسته‌ها از پیوندهای `/Markalar/<id>/<slug>.aspx` در صفحهٔ تنوع محصولات و استان‌ها از فهرست کشویی شهر یابندهٔ فروشگاه می‌آیند. یک ویژگی سایت مستند شده و دور زده نشده است: یابندهٔ فروشگاه به درگاهی (KuramPortal) ارسال می‌کند که به توکن‌های نشست زندهٔ صفحه نیاز دارد؛ پس نشانی فروشگاه به‌تفکیک شهر ارائه نمی‌شود. انتقال با جعل TLS کروم انجام می‌شود (`curl-cffi`، `chrome120` با چرخش)؛ درخواست‌ها با فاصلهٔ حدود ۰٫۸ ثانیه فرستاده می‌شوند؛ همه‌چیز فقط‌خواندنی است.

## نصب

```bash
uvx bim-mcp==0.1.0        # اجرای مستقیم (نیازمند uv)
# یا
pip install bim-mcp==0.1.0
bim-mcp    # سرور MCP را روی stdio راه‌اندازی می‌کند
```

## آزمون‌ها

```bash
python -m venv .venv && .venv/bin/pip install -e .
.venv/bin/python -m unittest discover -s tests -v
```

آزمون‌های آفلاین روی نمونه‌های ضبط‌شده اجرا می‌شوند (صفحات واقعی در ۲۰۲۶-۱۱-۱۰ گرفته شده‌اند)؛ آزمون‌های زنده به bim.com.tr وصل می‌شوند. در زمان ساخت، آزمون‌ها سبز بودند (برای شمارش به مخزن نگاه کنید) و یک آزمون دود (smoke) از طریق MCP stdio هم هست.
